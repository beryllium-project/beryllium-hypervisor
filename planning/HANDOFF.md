# Session handoff: not part of this repository

The session handoff was the private internal repository's development and
Project Manager record: the running account, from one working session to
the next, of what was done, what was decided, and what waited on the
responsible human. It is not part of this repository. Pages here that
link to it describe the project as it stood at the source commit.

The project's status is in the [roadmap](roadmap.md), part of the planning
record at the source commit, and in `RELEASE.md` at the repository's
root, this repository's release record.

## Helium source-of-truth boundary

Helium, the bounded QEMU pathfinder whose lessons Beryllium's planning
cites, is not part of this repository. Its current source is the separate
helium-te-poc repository, which keeps its own publication gate.
