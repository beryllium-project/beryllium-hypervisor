# The MVP guest pins (planning/mvp-m0-plan.md, Guest software, Budgets, and
# Tests and evidence; B7's guest/pins.txt with the MVP's outputs): the
# SHA-256 and size of the nolibc init, the management module, the Image,
# and every DTB that tools/build-guest.sh makes, the Image header facts,
# and the kernel banner, which both QEMU reference boots printed. They
# hold for the cross toolchain named on the last line. Since M1
# (planning/mvp-m1-plan.md, Guest software) the init has its roles and the
# Image B6's fragment and the MVP's, with /dev/mem; M2-1
# (planning/mvp-m2-plan.md, Scenarios and the harness) adds the anchor
# scenario's two DTBs, whose bootargs carry the host's and the protected
# domain's roles; and M2-4 (Guest software, Q2, Q16) the management
# module, be-mgmt.ko, which the Image's initramfs holds beside the init,
# now with M2's roles and HMAC-SHA-256, and the Image built with
# CONFIG_MODULES=y. M7-2 (planning/mvp-m7-plan.md, D-9, Q5 to Q7, Q13)
# adds the userland: the two `source` lines below, BusyBox and musl, each
# an external input never committed, by its release tag (lightweight) and
# that tag's commit, its release tarball's HTTPS URL and SHA-256, its
# detached signature's URL, the upstream key in guest/keys/ and the key's
# primary fingerprint, and its licence; and the outputs busybox (static,
# rv64imac and lp64, against musl) and musl-libc.a, with BusyBox in the
# Image's initramfs. Upstream on 2026-11-01: busybox.net marks 1.36.1
# (2023-05-19) its latest stable release, 1.37.0 and 1.38.0 unstable; musl
# 1.2.6 is musl.libc.org's latest release. Each tarball's tree is its tag's
# commit's (BusyBox's lacks the nine .gitignore files); busybox.net's
# .sha256 file gives the same SHA-256. Each key came from its project's
# site (https://busybox.net/~vda/vda_pubkey.gpg, Denys Vlasenko's DSA-1024
# key; https://musl.libc.org/musl.pub, RSA-2048), and keyserver.ubuntu.com
# gives the same fingerprint; both signatures use SHA-1 digests, which
# gpgv 2.4.9 accepts, so the SHA-256 pin is the binding check. musl's
# advisories through 1.2.6, CVE-2026-107891 (regcomp), CVE-2026-6042
# (iconv), and CVE-2026-40200 (qsort, 32-bit only), reach no guest code:
# BusyBox's link defines none of regcomp, regexec, iconv, and iconv_open,
# which tools/build-guest.sh checks, and the guest is 64-bit. M7-4
# (planning/mvp-m7-plan.md, Q4, D-4) adds the init's `be-anchor pause` and
# `be-anchor terminate` and its QEMU-only /init-hostile, a further link in
# the initramfs, and six DTBs: each scenario's shell DTBs, with
# rdinit=/init-shell (anchor's G0 alone), and G0's hostile DTB, with
# rdinit=/init-hostile.
# tools/guest-pins.py checks them; `build-guest.sh --unpinned` prints the
# output lines for a deliberate update.
