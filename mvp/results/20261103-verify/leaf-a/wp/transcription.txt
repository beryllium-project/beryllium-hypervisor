# WP arm: how each section 4 clause is transcribed (mvp/verify/wp/mvp-sbi-leaf.acsl and round-N.acsl)
section 4.1 -> mvp-sbi-leaf.acsl's logic: SPV, SPVP, GVA as BIT(h, 7), BIT(h, 8), BIT(h, 6) with BIT(v, n) = (v >> n) & 1; GPA(htval, stval) = (htval << 2) | (stval & 3); OPCODE(i) = (i >> 2) & 0x1f; HTINST_OK as written; INSIDE(a, base, n) = base <= a < base + n; MAPPED = INSIDE(window) or HAS_PAGE, HAS_PAGE and IN_PAGE over pages 0 to 2 (the type's three); PAGE as PAGE_IS(l, i, gpa), the lowest index i with p.bytes > 0 and INSIDE; W(pte) = BIT(pte, 2) == 1; ACCESS_FAULT 1, 5, 7 for 20, 21, 23 (0 elsewhere, never used: every use is under E2); VSTVEC_MODE(v) = v & 3
section 4.2 -> predicates E1 to E7, UNMAPPED (E7's first case), READ_ONLY (its second), ENTRY (their conjunction), KIND as D_kind_unmapped and D_kind_read_only
section 4.3 -> be_mvp_denial_decide's requires: D_valid (\valid_read of the four inputs, \valid(out)), D_separated (\separated of all five: "non-aliasing"), D_map_nowrap and D_pages_nowrap (sums below 2^64); nothing else
section 4.4 Result -> D_result (0 or 1), D_E1 to D_E7 (1 only if each E holds), D_complete (ENTRY implies 1); round 1 restates D_complete as D_complete_empty_window, D_complete_in_window, D_complete_outside_window, whose hypotheses (size 0; size not 0 and the GPA in the window; size not 0 and the GPA outside it) are exhaustive, so that their conjunction is D_complete itself
section 4.4 On 1 -> D_cause, D_kind_unmapped, D_kind_read_only, D_gpa, D_htval, D_htinst, D_stval, D_sepc, D_vsstatus, D_vstvec, D_time, D_inject_vscause, D_inject_vstval, D_inject_vsepc, D_inject_vsstatus_spp (bit 8 is SPVP(hstatus)), D_inject_vsstatus_spie (bit 5 is bit 1 of vsstatus), D_inject_vsstatus_sie (bit 1 is 0), D_inject_vsstatus_rest (every other bit: (x & ~0x122) == (vsstatus & ~0x122)), D_resume_pc (vstvec & ~3), each under \result == 1, the inputs read at Pre (\old)
section 4.4 On 0 -> D_zero_* for the fifteen fields, each under \result == 0
section 4.4 Frame -> assigns *out; "reads no object but the four inputs" and "Determinism and purity" have no WP goal of their own: the postconditions fix the result and every field of *out as functions of the four inputs' values
section 4.4 Runtime errors -> -wp-rte with -warn-unsigned-overflow and -warn-unsigned-downcast: every access valid, every unsigned operation within range, no signed overflow
section 4.5 access_fault -> AF_cause (scause 20, 21, 23 give ACCESS_FAULT; nothing for others), assigns \nothing; round 1 adds AF_other (0 for every other cause), proved, because the leaf calls access_fault before E2 and refuses on its 0 (section 4.5 says the leaf calls it under E2 only)
section 4.5 htinst_accepted -> HI_iff (1 iff HTINST_OK), assigns \nothing; round 1 adds HI_bool (0 or 1), proved: the leaf tests the result for truth
section 4.5 inside -> requires IN_nowrap; IN_iff (1 iff INSIDE); assigns \nothing; round 1 adds IN_bool (0 or 1), proved, for the same reason
section 4.5 leaf_at -> requires LA_valid, LA_nowrap; LA_page (PAGE_IS(i) implies \result == &leaves->page[i]); LA_none (no page: \result == \null); assigns \nothing; the loop: LA_index, LA_before (no earlier page holds gpa), loop assigns index, loop variant 3 - index
round 2 -> lemma E3_MASK (the leaf's three-bit test of hstatus is E3), proved in its own run with WP's bitwise tactics; assertions D_E3_here (at the call of htinst_accepted) and D_gpa_here (at the call of inside), each a goal
round 3 -> lemmas W_MASK ((pte & 4) == 0 is W negated) and HTVAL_SHIFT (htval << 2 stays below 2^64 for htval below 2^39, E4's bound), proved in the lemmas' run; leaf_at's LA_null (a null result: no page holds gpa) and LA_found (a non-null result is &page[i] for PAGE_IS(i), i = 0, 1, or 2), consequences of section 4.5's contract for a valid array of three, proved from the loop's invariant; assertions D_window_here (at the call of inside: the GPA, map->gpa_base, and map->size are the entry's) and D_place_here (at the call of leaf_at: the GPA and the cause are the entry's, the GPA is outside the entry's window, and HAS_PAGE, PAGE_IS for each page, and PAGE_READ_ONLY are the same at the call as at entry), each a goal
