# Every external pin this repository's experiments use: one line per pin,
#   <name> <kind: commit|tag|archive> <URL> <identifier> <sha256 or ->
# A `-` SHA-256 marks a pin that is cited but not yet fetched and verified;
# nothing is run from an unverified pin. For a commit pin, the SHA-256 is
# that of `git archive --format=tar <commit>` in the fetched repository.
# Beryllium's pins are commits of the repositories named in README.md.
#
# beryllium-m8-target is internal. It postdates console input (2026-11-01),
# so its mvp-sbi.c, mvp-ring.c, and ring-test.c differ from
# beryllium-snapshot's; deny-test.c is equal (git blob comparison,
# 2026-11-03). beryllium-m8-digests, also internal and later, adds
# mvp/verify/target-digests.txt, the frozen record of beryllium-m8-target.
#
# The experiment's route, the responsible human's choice of 2026-11-03
# ("let's go with codasip-latest"): Codasip's CHERI-RISC-V v0.9.3 stack
# under Codasip's QEMU branch. It replaces the provisional CHERI Alliance
# QEMU main (937b306b). Each commit is its branch's head on 2026-11-03:
#   cheri-alliance-qemu     codasip-latest (QEMU 8.1.0; riscv64cheristd)
#   cheri-alliance-llvm     codasip-cheri-riscv-20
#   cheri-alliance-linux    codasip-cheri-riscv-7.1
#   cheri-alliance-musl     codasip-cheri-riscv
#   cheri-alliance-opensbi  codasip-cheri-riscv-1.8.1
#   cheri-alliance-busybox  codasip-cheri-riscv-1_36_1
#   cheribuild              main (build orchestration only)
# python-distlib (PyPI, released 2026-10-16) is only for configuring QEMU
# 8.1, whose configure needs distlib; the host's Python 3.14 and pip 26
# lack it.
#
# The monitor run (experiments/monitor-run.sh, 2026-11-04): the MVP monitor
# from beryllium-dev-tip, unchanged. That commit was Beryllium's development
# tip from 2026-11-02 until 2026-11-04 01:13 US Pacific, when the M9 and M8
# lines were integrated; beryllium-integration is the development tip after
# that integration (6ff17c67, 2026-11-04 02:48), with M9's measurement log.
# beryllium-opensbi is upstream OpenSBI tag v1.6, as Beryllium's
# bringup/k3-b1/Makefile pins it; beryllium-opensbi-fw is the firmware file
# Beryllium's QEMU runs use, by the SHA-256 its records at beryllium-dev-tip
# name (mvp/results/20261029-rc/host/rehearsal/*/rehearsal.txt).
